# adobe-stock-metadata-pro
Automated metadata manager and editor tool for Adobe Stock contributors.

---

## 🇬🇧 English

### How to Download
1. Go to the **Releases** section on the right side of this repository.
2. Click on the latest release.
3. Under **Assets**, click on `Adobe.Stock.Metadata.pro.zip` to download the ZIP file.

### How to Install & Use in Chrome Browser
1. **Extract the File:** Extract/unzip the downloaded `Adobe.Stock.Metadata.pro.zip` file on your computer.
2. **Open Extensions Page:** Open Google Chrome and go to `chrome://extensions/` in the address bar (or click on the 3 dots menu > Extensions > Manage Extensions).
3. **Enable Developer Mode:** Turn ON the **Developer mode** toggle switch at the top-right corner of the Extensions page.
4. **Load Extension:** Click on the **Load unpacked** button at the top-left corner.
5. **Select Folder:** Select the unzipped folder containing the extension files.
6. **Done!** The extension will be installed and ready to use in your browser.
