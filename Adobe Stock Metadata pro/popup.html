How it works

  1. সর্বপ্রথম আপনার যেকোনো API Keys এড করুন: Gimini,ChatGpt অথবা Claude
  2. Go to your Adobe Stock contributor.stock.adobe.com upload page.
  3. Click the AI badge on any thumbnail (photo, vector, EPS/AI, SVG, or video), or the Get All Metadata button to process every file.

Tip: Raise your limit

  • যত বেশি Api Key অ্যাড করবেন তত বেশি ব্যবহার করতে পারবেন।সহজে লিমিট শেষ হবে না ,অথবা যদি আপনার সাবস্ক্রিপশন নেওয়া থাকে google এর কাছ থেকে তাহলে অনেক Api এড করা দরকার নেই-
  • The more Api Keys you add, the more you can use. The limit will not end easily, or if you have a subscription from Google, then there is no need to add many Apis.
